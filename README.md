# A0509 Python Learning Lab

비전공 대학생이 자연어, Python 코드, 6축 로봇의 관절 움직임을 한 화면에서 연결해 학습하는 정적 웹 프로토타입입니다.

## 현재 프로토타입

- 실제 A0509 URDF와 흰색 DAE 메시를 사용합니다.
- API Key가 없을 때는 자연어 입력을 로컬 규칙 엔진이 안전한 Python 예제로 변환합니다.
- OpenRouter AI 모드에서는 GPT-6 Sol Pro가 동작 계획을 검토하고 Claude Sonnet 5가 Python 코드와 초보자 설명을 만듭니다.
- 생성된 코드를 편집하고 브라우저 안의 Pyodide로 실행할 수 있습니다.
- Pyodide를 불러오지 못하면 제한된 학습용 실행기가 자동으로 대신 실행합니다.
- SCHUNK/CADENAS 공식 STEP AP214를 기술적으로 삼각형화한 공개 배포용 Co-act EGP-C 40-N-N-M1013 GLB를 `tool0`에 장착합니다.
- 공개 GLB에는 수동 재질 변경, 메시 이름 변경, 핑거 재분류 및 애니메이션 그룹을 넣지 않습니다. 브라우저가 원본 부품명과 파지부 좌표를 함께 검사한 뒤 실행 중에만 편측 6 mm 개폐 그룹을 구성합니다.
- CAD 장착면부터 핑거 끝까지 측정한 135.45 mm를 TCP 초기값으로 반영하고, 선택한 팔레트 칸마다 P2/P3/P4/P5 자세를 동적으로 계산합니다.
- 12개 색상 큐브를 각각 선택하거나 한 번에 순차 이동할 수 있으며, 큐브 상단 75% 지점을 잡아 출발 칸과 같은 위치의 목표 구멍에 배치합니다.
- Supabase, 로그인, 애플리케이션 서버, 실제 로봇 연결은 포함하지 않습니다.

## OpenRouter 사용

화면의 `OpenRouter 두 모델 함께 사용하기`를 펼치고 개인 API Key를 입력하면 AI 모드를 사용할 수 있습니다. 키는 JavaScript 변수에만 저장되며 페이지를 새로고침하면 사라집니다.

이 방식은 개인 프로토타입 검증용입니다. 여러 학생에게 배포할 때는 브라우저에 공용 키를 넣지 말고 별도 인증 프록시를 구성해야 합니다.

## 실행

ES Module과 URDF 파일을 사용하므로 `index.html`을 더블클릭하지 말고 정적 HTTP 서버로 여십시오.

Python이 설치되어 있으면 다음처럼 실행합니다.

```powershell
cd dist
python -m http.server 4173
```

Node.js가 설치되어 있으면 프로젝트 루트에서 다음 명령도 사용할 수 있습니다.

```powershell
node tools/serve.mjs
```

브라우저에서 `http://localhost:4173`을 엽니다. Python이 없으면 VS Code Live Server 또는 다른 정적 서버를 사용할 수 있습니다.

## 대표 자연어 입력

- `홈 자세로 돌아가 줘`
- `작업 준비 자세로 이동해 줘`
- `1번 관절을 오른쪽으로 30도 돌려 줘`
- `3번 관절을 -45도로 이동해 줘`
- `P2 위치로 천천히 이동해 줘`
- `인사 동작을 보여 줘`
- `빨간 큐브를 목표 위치로 옮겨 줘`
- `모든 큐브를 하나씩 옮겨 줘`

## 안전 범위

이 웹 앱은 관절운동학 시각화 도구입니다. 동역학, 충돌 회피, 안전 정지 및 실제 로봇 제어 기능은 없습니다.

현재 그리퍼는 실제 보유 장비로 확인된 SCHUNK Co-act EGP-C 40-N-N-M1013 공식 STEP 조립품에서 변환한 1.83 MB GLB입니다. 공개 GLB는 18개 메시 부품을 유지하며, 좌우 핑거 가동 그룹과 편측 6 mm 이동은 브라우저 실행 시 생성됩니다. 웹 로딩 실패 시에만 절차적 대체 형상이 표시됩니다. TCP 135.45 mm는 CAD 바운딩 박스 기반 초기값이므로 실제 장비 적용 전에는 현장 TCP 측정으로 최종 보정해야 합니다.

공개 GLB는 0.35 mm 선형 허용오차와 0.35 rad 각도 허용오차로 생성된 53,494개 삼각형의 기술적 포맷 변환본입니다. 원본 CAD에는 CC BY-ND 4.0 라이선스가 적용되어 있으며, 공개 GLB에도 CADENAS GmbH와 SCHUNK SE & Co. KG의 권리 표시와 변환 사실을 유지합니다. 변환본의 공개 배포 적합성에 대한 가장 확실한 확인 방법은 권리자의 서면 확인입니다. 자세한 출처와 라이선스는 `THIRD_PARTY_NOTICES.md`에서 확인할 수 있습니다.

## GitHub Pages 배포

`main` 브랜치에 푸시하면 `.github/workflows/deploy-pages.yml`이 `dist` 폴더를 GitHub Pages에 배포합니다. 저장소 설정의 Pages 소스는 `GitHub Actions`로 지정해야 합니다.

공개 저장소에는 `egpc40-public.glb`만 포함합니다. 수동 재질과 내장 핑거 그룹을 사용한 로컬 전용 `egpc40.glb`, 절대 경로가 들어 있는 로컬 매니페스트, 백업 폴더 및 `node_modules`는 `.gitignore`로 제외됩니다.

공개용 그리퍼가 기대와 다르면 `dist/index.html`의 다음 값을 `false`로 바꾸면 로컬 전용 GLB 방식으로 즉시 되돌아갑니다. 이 로컬 전용 파일은 공개 Git 기록에 추가하지 마십시오.

```js
const USE_PUBLIC_GRIPPER_ASSET = false;
```
